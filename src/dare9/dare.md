In this challenge, we test your knowledge of using if-else conditional statements to automate decision-making processes. 

#### Task
Given an integer, _N_, perform the following conditional actions:

- If _n_ is odd, print `Weird`
- If _n_ is even and in the inclusive range of 2 to 5, print `Not Weird`
- If _n_ is even and in the inclusive range of 6 to 10, print `Weird`
- If _n_ is even and greater than 20, print `Not Weird`

Complete the stub code provided in your editor to print whether or not  is weird.

#### Input Format

A single line containing a positive integer, _n_.

#### Constraints

- _1 <= n <= 100_

#### Output Format

Print `Weird` if the number is weird; otherwise, print `Not Weird`.

#### Sample Input 0

    3

#### Sample Output 0

    Weird

#### Sample Input 1

    24

#### Sample Output 1

    Not Weird
